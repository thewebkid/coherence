# admin-dashboard Specification

## Purpose
Defines navigation within the admin dashboard to switch between management views (such as Interpretive Works submissions and Weekly Signal authoring).

## Requirements

### Requirement: Admin Dashboard Navigation
The system SHALL provide navigation within the admin dashboard to switch between different management views.

#### Scenario: Switching to Weekly Signal management
- **WHEN** the administrator selects "Weekly Signal" from the dropdown or navigation menu
- **THEN** the Interpretive Works management interface is hidden
- **AND** the Weekly Signal authoring interface is displayed
